# Yuhang's Web Space

Static personal web space for GitHub Pages: part project archive, part notes, part resume entrance.

## Files

- `index.html` - sidebar-based home feed
- `resume.html` - recruiter-facing resume page
- `projects/` - project case-study pages
- `notes/` - personal and technical notes
- `styles.css` - responsive dark/glass visual system
- `script.js` - mobile sidebar, search, and tag filtering
- `assets/` - portrait, CV, and favicon assets
