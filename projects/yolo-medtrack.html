Project / Surgical Video Understanding

YOLO-MedTrack

A real-time surgical instrument segmentation and tracking system built as a Medical Robotic Intelligence project at NUS.

YOLOv11-Seg ByteTrack MedTrack EndoVis 2018

Problem

Robotic-assisted surgery videos contain instruments moving through low-contrast scenes with occlusion, scale variation, and changing viewpoints. The task was framed as video instance segmentation: detect, segment, classify, track, and analyze instrument motion across frames.

Approach

I designed a Python-based pipeline combining YOLOv11-Seg with ByteTrack / MedTrack-style tracking-by-detection. The system connects object detection, semantic segmentation, cross-frame association, and trajectory analysis to improve temporal consistency.

Evaluation

Experiments used the EndoVis 2018 dataset and compared detector-tracker combinations through mAP, Dice, MOTA, ID switches, FPS, and latency to reason about accuracy-speed trade-offs.
