## Context

At Tencent Singapore, I worked on AI workflows for game operations. The goal was to move parts of operational analysis from manual dashboard inspection toward natural-language-driven, tool-enabled workflows.

## System Direction

The agent framework emphasized memory management, skills-based capability abstraction, and optimized tool-calling flows so analysis capabilities could be reused across different business analysis scenarios.
